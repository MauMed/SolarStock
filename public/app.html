Sucursales (SIAT)

Deben coincidir con las registradas en Impuestos Nacionales: la Casa Matriz es codigo 0; si el cliente solo tiene casa matriz, no necesita crear mas. Cada sucursal puede tener sus propias credenciales SIAT (pestana SIAT).

Almacenes

Son internos (el SIN no los ve) y cuelgan de una sucursal. Un mismo local puede tener varios (deposito, sala de ventas, transito).

Conciliacion con Impuestos Nacionales

Importa el registro de ventas del SIN (CSV de la oficina virtual). El sistema cruza cada factura: si fue emitida aqui, la marca conciliada; si fue emitida desde otro aplicativo, ubica los productos por codigo y descuenta el stock automaticamente para que el inventario quede cuadrado.

Si el cliente tiene SolarCRM, SolarStock se convierte en su Punto de Venta y el Catalogo de SolarCRM se alimenta automaticamente con estos productos (altas, precios, fotos y stock). Configuracion guiada, sin programar: 3 pasos.

Paso 2 · Conectar

Paso 3 · Pega esto en SolarCRM

En SolarCRM: Configuracion → Integraciones → SolarStock, pega este bloque y guarda. Listo.

Mini guia de integracion

1 · Autenticacion

curl -H "X-Api-Key: TU_LLAVE" https://tudominio.com/api/v1/productos

2 · Sincronizar productos desde tu ERP (Odoo, SAP, etc.)

POST /api/v1/productos/sync
{ "productos": [
  { "codigo_interno": "FER-001", "nombre": "Martillo 16oz",
    "codigo_barras": "7791234567890", "precio_venta": 55,
    "externo_ref": "odoo-8812" }
]}

3 · Consultar stock en tiempo real

GET /api/v1/stock
-> [{ "codigo_interno": "FER-001", "almacen_id": 1, "cantidad": "20.000" }]

4 · Registrar una venta externa (descuenta stock, factura opcional)

POST /api/v1/ventas
{ "sucursal_id": 1, "almacen_id": 1,
  "items": [{ "producto_id": 12, "cantidad": 2, "precio_unit": 55 }],
  "facturar": true, "siat_config_id": 1 }

5 · Empujar ventas facturadas en OTRO sistema (conciliacion)

POST /api/v1/conciliacion/ventas
{ "cuf": "8727F63A...", "numero_factura": 1044, "monto_total": 110,
  "items": [{ "codigo": "FER-001", "cantidad": 2 }] }
-> el inventario se descuenta automaticamente

6 · Webhooks (nosotros te avisamos)

Eventos: stock.bajo, venta.creada, factura.valida. Cada POST incluye la cabecera X-Firma = HMAC-SHA256(payload, secreto) y reintentos exponenciales.

// Verificacion en tu servidor (PHP)
$ok = hash_equals($_SERVER['HTTP_X_FIRMA'],
  hash_hmac('sha256', file_get_contents('php://input'), $secreto));
